### 📖 About This Project
This repository contains my personal portfolio website and collection of DevOps automation scripts. Built to showcase my skills in Infrastructure, CI/CD, and Linux Administration.

### ✨ Features
- ⚡ Fully Responsive Portfolio Website
- 🐳 Dockerized Deployment
- 🚀 CI/CD with GitHub Actions
- 🔧 Infrastructure as Code (IaC) examples
- 📊 Linux Server Monitoring Scripts
- 🌐 Nginx Reverse Proxy Configurations

### 🛠️ Tech Stack Used
- **Frontend:** HTML5, CSS3, JavaScript
- **DevOps:** Docker, Nginx, Linux, GitHub Actions
- **Tools:** VMware, Git, Bash, Networking
